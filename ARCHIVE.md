# Archive Notice

This project is archived and no longer actively maintained.

## Background

Fluxagama was created around 2012 as a learning project when my kids were getting into programming. It served its purpose - we learned Python, PyGame, and basic game development concepts together. The numerous open issues were intended as exercises for us to implement, following the classic Space Invaders gameplay.

## Current Status

The game runs and demonstrates basic concepts:
- Game loop and sprite management
- Collision detection
- Input handling
- Score tracking

However, we never got around to implementing full gameplay (enemy movement, AI, game over conditions, etc.). The project has been dormant since 2012, with only recent updates to make it run on modern Python/PyGame versions.

## Future

This repository is now archived. Feel free to fork it if you'd like to use it as a starting point for your own learning journey!
